# 🎮 **2D Game Engine**  
**Un moteur de jeu 2D en C++ développé avec SFML et Box2D, avec une démo de platformer**

---

## 📜 **Description du projet**  

Ce projet est un **moteur 2D** personnalisé développé en **C++**, utilisant **SFML** pour le rendu et la gestion des entrées, et **Box2D** pour la simulation physique.

Le projet vise à construire une architecture de moteur modulaire et extensible, capable de prendre en charge les systèmes de gameplay 2D classiques.  
Une démo de platformer est incluse pour illustrer et valider les systèmes cœur du moteur dans un scénario de jeu concret.

---

### 🚪 **Fonctionnalités principales**  

1. **Systèmes cœur du moteur**  
   - Architecture de la boucle de jeu  
   - Gestion des scènes et des niveaux  
   - Pipeline de rendu via SFML  
   - Intégration physique via Box2D  

2. **Systèmes d'entités et de gameplay**  
   - Contrôleur du joueur avec déplacement et interactions physiques  
   - Gestion et réponse aux collisions  
   - Système basique de comportement des ennemis  
   - Gestion de la vie et de l'état du jeu

3. **Gestion des niveaux**  
   - Deux niveaux jouables  
   - Agencement de carte structuré pour le platformer  

4. **Systèmes d'état de jeu et d'interface**  
   - Menu principal  
   - Écran de game over
   - Score et chronomètre

5. **Démo platformer**  
   - Une démo jouable inspirée des mécaniques classiques de platformer  
   - Illustre le déplacement, les collisions, les ennemis et les transitions de niveau  
   - Sert de couche de validation pour les systèmes cœur du moteur

## 🚀 **Installation et mise en route**  

### **Prérequis**  
- **Git**  
- Un compilateur C++ (Visual Studio recommandé sous Windows)  
- SFML et Box2D installés  

### **Étapes d'installation**  

1. **Cloner le dépôt**  
   - Cloner le projet sur votre machine via un terminal :  
     ```bash
     git clone https://github.com/HugoFlandrin/2D-Game-Engine
     ```  

2. **Ouvrir le jeu**
   - Allez dans "2D-Game-Engine\x64\Debug" et ouvrez le fichier nommé **MarioLike.exe**. Vous êtes prêt à jouer ! 🎉
